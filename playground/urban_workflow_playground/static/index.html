Schémas d'événements (JSON Schema en YAML)

Référencés par DEFINE EVENT … AS @nom; — le payload est validé (socle commun + schéma) à chaque évaluation.

Une liste JSON d'événements, rejoués dans l'ordre sur un moteur en mémoire.

  • Ctrl+Espace : complétion (aussi automatique en tapant).
  • La complétion est contextuelle : événements après ON EVENT, états après SWITCH, règles après WHEN/AND/OR/NOT, actions après EXECUTE, chemins après @.
  • Les erreurs (syntaxe et validation) sont soulignées dans l'éditeur et listées sous celui-ci — cliquer pour y aller.
  • DEFINE EVENT X '…' AS @schema UNIQUE (Prop, …); : le schéma (panneau Paramétrage) valide le payload ; UNIQUE et la propriété DedupKey de l'émetteur (prioritaire) bloquent les doublons en simulation.
  • Référence du langage : docs/guide-dsl.md.
